教學

按 ? 開關，Esc 關閉
  • 1截圖後按 Ctrl+V 貼上，或把照片拖進中間深色底的照片區；沒照片先按「載入範例」。
  • 2照片太小先用滾輪放大，再依序點 4 個角：左上 → 右上 → 右下 → 左下。
  • 3點完第 4 點，斜的面立刻拉正，自動放進左邊「圖集」（＝很多貼圖排在一張大圖上）。
  • 4點歪了就拖角點微調，結果即時更新；Ctrl+Z 隨時復原。
  • 5拓第 2 張：在照片空白處再點 4 個角，會自動開新框（或先按 N）。
  • 6圖集裡拖曳搬位置；拉選取外框角上的金色小方塊改尺寸；R 旋轉。
  • 7按左邊圖集上方的金色「匯出材質組」→ 五張貼圖＋UV JSON，丟進引擎就能用。
  • 8做到一半按頂欄「存檔」（Ctrl+S）；重新整理會清空，下次用「開啟」接著做。
  • ▱四點透視 Q：平面但拍斜了。武器面板、建築牆面、海報。
  • ⌒彎邊四點：先放大，把邊中間小圓拖到標籤真正的弧形邊（白點＝直線、金點＝有彎）。瓶身、桶身標籤。
  • ⬠多點 P：形狀不規則、外面要透明。貼花、破損鐵皮、葉片；Enter 收合。
  • ▭矩形 M：已經是正面，只要裁一塊。UI 圖示、地磚、截圖裡的面板。
  • ◯橢圓 O：圓形物件。儀表盤、徽章、井蓋，外面透明。
  • ◠曲線 C：上緣 3 點＋下緣 3 點展平。罐頭、柱子這類整圈圓柱。
  • ?不確定用哪個？先用四點，彎的再加控制點。
  • 1先按「自動排」一次排好，再手動微調位置。
  • 2看得到的面（武器握把、招牌）拉大，背面、底部縮小：像素給在鏡頭看得到的地方。
  • 3拉選取外框角上的金色小方塊縮放＝用新尺寸重新拓，不會越拉越糊；Alt＋拉角＝自由比例。
  • 4滾輪放大圖集精修小圖，Shift＋拖曳平移，Home 回全覽。
  • 5保留 Padding 4px＋「外擴」，引擎做 mipmap 時才不會吃到隔壁的顏色。
  • 6紅框＝重疊或超出圖集，匯出前清乾淨。
  • 7圖集用 1024／2048 這種 2 的次方，引擎壓縮最穩。
  • 1右欄「輸出」選目標引擎：檔名與法線 Y 軸自動對應。
  • UUnity：點 _Normal 那張 → Inspector 的 Texture Type 改成 Normal map → 按 Apply。
  • UEUnreal：雙擊 _R、_AO 貼圖 → 把 sRGB 勾掉 → 存檔（法線已自動用 DirectX）。
  • BBlender：_nor 的 Image Texture 節點 Color Space 選 Non-Color → 接到 Normal Map 節點。
  • {}UV JSON：每張圖的 u0 v0 u1 v1（左上為原點），寫腳本對 UV 用。
  • Z「匯出全部 ZIP」：每張拓印一個 PNG，檔名＝來源檔名_拓印名.png。
  • 例瓶身標籤：彎邊四點拓平 → 單張匯出 → 直接貼到瓶子模型的 UV。
  • 拓拓印：把照片上的一塊拉成正面的貼圖。
  • 透透視校正：用 4 個角把拍斜的面拉正（數學上叫單應性）。
  • 圖圖集 Atlas：很多小貼圖排在一張大圖上，引擎少切換材質。
  • UVUV：模型表面對應到貼圖上的座標。
  • 縫無縫 Seamless：上下左右接起來看不到接縫，可以重複平鋪。
  • 光去光影 De-Light：拉平照片的明暗，貼圖不帶固定光源。
  • PPBR 五張：Albedo 顏色／Normal 凹凸／Roughness 粗糙／AO 縫隙陰影／Height 高度。
  • 擴外擴 Dilation：把邊緣像素往外補幾格，防止接縫露出底色。
