## 1. 比對結論（Puck's Seamlessifier + Ripper vs 我們 v2.2）

| Puck 有、我們沒有或較弱 | 我們怎麼補 | 里程碑 |
|---|---|---|
| **多邊形 ripper 可拉彎邊**（四角＋邊上加控制點，彎曲／桶狀表面也能拉正；這是它「polygon-based perspective correction」的核心） | 四點框升級成「**可彎邊四點框**」：每條邊可加 1～2 個控制點拖成曲線（二次／三次貝茲）。取樣：先用 4 角算單應性 H，把控制點映到校正空間，在校正空間做 **Coons patch**（四條邊界曲線的雙線性混合）得到 source(u,v)，再用 H⁻¹ 映回原圖取樣。邊是直線時結果＝原本的純單應性（不能退步）。 | M1 |
| 每個 ripper 都有**即時個別輸出預覽**，一眼看所有拓印結果 | 右欄加「拓印清單」：每個 region 一張縮圖＋名字，點了切換目前 region；縮圖隨結果更新 | M1 |
| 圖集可縮放檢視 | 圖集工作區：滾輪縮放、Shift 拖曳／中鍵平移、`Home` 回全覽；4096 圖集上小圖也能精修 | M1 |
| 匯出三種：單張／全部拓印／整張圖集，檔名跟來源圖 | 「匯出全部拓印」：零依賴自寫 **store-only ZIP**（不壓縮，約 60 行）一次下載；檔名 `來源檔名_拓印名.png`；單張、圖集維持 | M1 |
| Slow mode（高解析度時降負擔） | 拖控制點期間用 ¼ 解析度預覽，放開才全解析度重算（若已有類似機制，確認並寫進 SKILL） | M1 |
| 無縫化：細節回復、對比、光影校正 | 無縫面板加「**細節回復**」（高通加回）與「**對比**」兩支滑桿；去光影已有 | M2 |
| 像素風工作流 | 已有像素取樣；確認匯出時 nearest 不糊 | M2 |

**我們已經贏的（不要動壞）**：五種框選模式、PBR 五張整組匯出＋UV JSON＋引擎命名、專案存讀、去光影、接縫分數、Ctrl+V 貼圖、墨金日夜版。

## 2. M3 以人為本：教學系統（南瓜最在意）

1. **首次開啟導覽**：4 張卡（貼照片 → 點四角 → 排圖集 → 匯出），每張卡 spotlight 到對應 UI 區塊＋一句白話＋一個動作提示；「下一步／略過／不再顯示」（localStorage 記住）。頂欄常駐「**教學**」按鈕可重開。
2. **內建範例圖**：不放真照片（去敏），用 canvas 程序化畫一張「斜著拍的機器面板」（帶透視的格線＋文字＋旋鈕＋些微漸層光影），按「載入範例」就有東西可練；導覽第 2 步自動載入範例並預放 4 個角，讓人看到「點完角 → 立刻拓平」的魔法。
3. **教學面板**（取代／擴充 `?`）：分頁「30 秒上手｜五種框法何時用｜排 UV 訣竅｜匯出到 Unity／Unreal／Blender｜名詞表｜快捷鍵」。每頁 ≤ 8 行白話＋小圖示；GG 美術實際情境舉例（武器面板、建築牆面、瓶身標籤）。
4. **空狀態提示**：畫布沒圖時中央顯示「把截圖 Ctrl+V 貼進來，或拖照片進來，或按『載入範例』」。
5. `docs/教學.md`：白話步驟＋截圖（Playwright 用範例圖跑一遍截的），給同事看的版本。
